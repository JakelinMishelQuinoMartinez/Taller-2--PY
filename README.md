 TALLER 2: Desarrollo de una App para Administrar un Inventario
Creación de una aplicación de consola para gestionar el inventario de una tienda pequeña, poniendo en práctica la utilización de Git y GitHub para versionar el proyecto, aplicando ramas y commits estructurados.

## 1. Descripción del Sistema
El sistema permite registrar, consultar y modificar información de los productos disponibles en el inventario de una tienda pequeña.
Cada producto almacena la siguiente información:
- Nombre del producto
- Precio
- Cantidad disponible en inventario

El Menú es el siguiente:
### 1.1 Agregar producto
Permite registrar un nuevo producto en el inventario.
### 1.2 Listar productos
Muestra la información de todos los productos regirtrados en el inventario.
### 1.3 Actualizar cantidad
El usuario ingresa el nombre del producto y el sistema le permite modificar la cantidad disponible del mismo.
### 1.4 Eliminar producto
Permite eliminar un producto del inventrairo.
### 1.5 Calcular valor total del inventario
El sistema calcula el valor total del inventario mediante fórmula matemática.
### 1.6 Salir
El programa se mantiene en ejecución hasta que el usuario selecione la opción ***Salir***.

## 2. Tecnologías utilizadas
- Python
- GitHub
- Visual Studio Code

## 3. Instrucciones de ejecución
Desde la consola se ejecuta: 
> python3 main.py
